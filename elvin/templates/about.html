About

Elvin - autonomous agentic coder

Elvin runs entirely on your computer (with optional cloud models). It plans, writes, tests and verifies code, and asks for your permission before every change or command.

How Elvin keeps your code safe

  • Permission dialogs - every file change, command, install and load test is shown to you first, with the exact diff.
  • Folder boundary - AI writes are confined to the project folder (absolute paths, "..", symlinks and the .git folder are refused).
  • Crash-safe journal - change sets are all-or-nothing, so network drops, crashes or blackouts never leave half-written files.
  • Timestamped versions - hash-chained snapshots after every step, stored in PostgreSQL and on your disk, verifiable at any time.
  • Library gate - every library Elvin wants to use is checked on OSV.dev first; vulnerable or non-existent packages are blocked.
  • Sandbox - commands and screenshots run in a separate container with no secrets and no database access.
  • ClamAV - uploads, images and cloned repositories are virus-scanned before they enter your workspace.
